# RootlessWM

RootlessWM is a native Windows tiling window manager inspired by DWM, focused on keyboard-driven window management and predictable layouts.

## Capabilities

- Automatic tiling of eligible top-level Windows applications.
- Master-and-stack window management.
- Layouts: `MasterLeft`, `MasterTop`, `Monocle`, and `Floating`.
- 9 independent workspaces, with independent workspace state per monitor.
- Multi-monitor support with automatic monitor work-area discovery.
- Status bar with system and user-defined modules.
- Built-in rofi-style application runner.

## Prerequisites

- Windows 11
